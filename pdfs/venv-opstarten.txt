Stappenplan: venv opzetten op een Linux-computer

1. Controleer je Python-versie

bash
python3 --version

Minimaal Python 3.8 nodig. Staat Python er niet (volledig) op:

bash
sudo apt install python3 python3-venv python3-pip

2. Maak een projectmap

bash
mkdir ~/mijn-project && cd ~/mijn-project

Zet hier connect.py en je andere bestanden in.

3. Maak de virtuele omgeving aan

bash
python3 -m venv venv

Dit maakt een map venv/ met een eigen, losstaande Python-installatie. Je systeem-Python blijft schoon.

4. Activeer de venv

bash
source venv/bin/activate

Je ziet nu (venv) voor je promptregel. Vanaf nu gebruiken python en pip de venv-versie, niet je systeembrede installatie.

5. Werk pip bij

bash
pip install --upgrade pip

6. Installeer wat je nodig hebt

bash
pip install requests

Voor dit script heb je requests alleen nodig als je de http-modus gebruikt — de tcp- en raw-http-modus werken met pure Python, zonder extra installatie. Optioneel, voor zwaarder CTF-werk:

bash
pip install pwntools

7. Leg vast wat je hebt geïnstalleerd

bash
pip freeze > requirements.txt

Zo kun je de omgeving later of op een andere machine herbouwen met pip install -r requirements.txt.

8. Script draaien

bash
python3 connect.py tcp --host 127.0.0.1 --port 1337

Dit moet elke keer opnieuw na het openen van een nieuwe terminal (stap 4 herhalen).

9. Venv verlaten

bash
deactivate
